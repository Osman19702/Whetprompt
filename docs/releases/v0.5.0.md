## Whetprompt 0.5.0 — Windows x64 installer

Whetprompt is PromptFixer under a new name. It lints, scores and rewrites LLM prompts with a built-in local model (Qwen3 4B), and nothing you type leaves your machine. Cloud providers (Anthropic, OpenAI, Gemini, OpenRouter, Ollama) are optional.

**New in 0.5.0: the new name, and a model that starts on a fresh Windows.** PromptFixer is now Whetprompt, and the installer, the website ([osman19702.github.io/Whetprompt](https://osman19702.github.io/Whetprompt/)) and the repository follow. Installed over PromptFixer, it replaces the old app, and the library, your `.env` and the downloaded model carry over by themselves. The built-in model now also starts on a Windows machine that has never had Microsoft's Visual C++ runtime, because the installer brings it; 0.4.0 stopped there with "NoBinaryFoundError".

Also new: the window fits a 1080p laptop screen at 125% scaling, Retry on a local-model error says what it is doing, the model stays loaded until you quit, as it did before 0.3.0, and the models-on-disk row is gone from the main screen. Everything else is in [CHANGELOG.md](../../CHANGELOG.md#050---2026-10-23).

**Download:** `Whetprompt-0.5.0-win-x64.exe` (339.8 MiB). Windows 10/11, 64-bit. The model (2.5 GB, or the 1 GB "lite" tier) is downloaded on first run into `%USERPROFILE%\.whetprompt\models`, unless PromptFixer already downloaded it into `%USERPROFILE%\.promptfixer\models`, which Whetprompt then uses.

**Upgrading from PromptFixer 0.4.0:** run the new installer over the old one. It replaces PromptFixer; on the page that asks where to install, choose `C:\Program Files` to get `C:\Program Files\Whetprompt` (the suggestion is a `Whetprompt` folder inside PromptFixer's). On its first start it copies your library (`%APPDATA%\PromptFixer\data\library.json`) and `.env` into `%APPDATA%\Whetprompt\`. The old folder is left as it was.

**Verify:** installer SHA-256 `d420ea0f63cfd623265287dca0d025b8f9f76d9eb22fbf591d60371bea5d7b12` (`SHA256SUMS.txt` is attached). PowerShell: `(Get-FileHash .\Whetprompt-0.5.0-win-x64.exe).Hash.ToLower()` must equal it.

**Not code-signed yet:** Windows shows "Windows protected your PC" → *More info* → *Run anyway*. Compare the hash first if in doubt. Full guide: `docs/INSTALL.md`.

**macOS:** no disk images for 0.5.0 yet. The macOS download is still 0.4.0, from before the rename, so the app it installs is called PromptFixer; its images and their hashes are on the [v0.4.0 release](https://github.com/Osman19702/Whetprompt/releases/tag/v0.4.0).

Why the installer is this large: it ships prebuilt CPU, Vulkan and CUDA llama.cpp backends so the right one is picked at runtime, and now the Visual C++ runtime next to them. The `.blockmap` is only for future differential updates.
