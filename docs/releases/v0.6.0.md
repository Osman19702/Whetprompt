## Whetprompt 0.6.0 — Windows x64 installer, and the Microsoft Store

Whetprompt lints, scores and rewrites LLM prompts with a built-in local model (Qwen3 4B), and nothing you type leaves your machine. Cloud providers (Anthropic, OpenAI, Gemini, OpenRouter, Ollama) are optional.

**New in 0.6.0: Whetprompt in the Microsoft Store.** The same app, from the same build as this installer, comes as a Microsoft Store package: the Store installs and updates it, and it opens without the "Windows protected your PC" screen. A Store install keeps its library and the model it downloads in the storage Windows gives it, and uninstalling it removes them; on a PC that already has this installer's version, the two share its library and model. [docs/INSTALL.md](../INSTALL.md#the-microsoft-store-version) has the details.

Also new: a **Report** link beside every rewrite, for one that is harmful or inappropriate. It opens a report form on GitHub in your browser, with the app's version and model filled in and nothing you or the model wrote. And the app no longer carries its dependencies' JavaScript source maps, which nothing runs. Everything else is in [CHANGELOG.md](../../CHANGELOG.md#060---2026-10-23).

**Download:** `Whetprompt-0.6.0-win-x64.exe` (TBD MiB). Windows 10/11, 64-bit. The model (2.5 GB, or the 1 GB "lite" tier) is downloaded on first run into `%USERPROFILE%\.whetprompt\models`, unless PromptFixer already downloaded it into `%USERPROFILE%\.promptfixer\models`, which Whetprompt then uses. Installing over 0.5.0 keeps your library and the model.

**Verify:** installer SHA-256 `TBD` (`SHA256SUMS.txt` is attached). PowerShell: `(Get-FileHash .\Whetprompt-0.6.0-win-x64.exe).Hash.ToLower()` must equal it.

**Not code-signed yet:** Windows shows "Windows protected your PC" → *More info* → *Run anyway*. Compare the hash first if in doubt. Full guide: `docs/INSTALL.md`. The Store version is signed by the Store.

**macOS:** no disk images for 0.6.0 yet. The macOS download is still 0.4.0, from before the rename, so the app it installs is called PromptFixer; its images and their hashes are on the [v0.4.0 release](https://github.com/Osman19702/Whetprompt/releases/tag/v0.4.0).

Why the installer is this large: it ships prebuilt CPU, Vulkan and CUDA llama.cpp backends so the right one is picked at runtime, and the Visual C++ runtime next to them. The `.blockmap` is only for future differential updates.
