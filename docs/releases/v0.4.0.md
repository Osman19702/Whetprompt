## PromptFixer 0.4.0 — Windows x64 installer, macOS disk images

Lints, scores and rewrites LLM prompts with a built-in local model (Qwen3 4B); nothing you type leaves your machine. Cloud providers (Anthropic, OpenAI, Gemini, OpenRouter, Ollama) are optional.

**New in 0.4.0: a website, and a way to reach it from the app.** [osman19702.github.io/PromptFixer](https://osman19702.github.io/PromptFixer/) says what PromptFixer does, offers the latest installer with its size and SHA-256, and lists what changed in every release, newest first. It is rebuilt whenever a release is published, from the release itself, so the download it offers is always the one on GitHub. In the app, **What's new** in the top bar opens that page in your own browser. It is a link and nothing more: the app never requests the site, there is still no update check, and the "nothing leaves your machine" test runs on every push as before.

Everything else is in [CHANGELOG.md](../../CHANGELOG.md#040---2026-09-27).

**Download:** `PromptFixer-0.4.0-win-x64.exe` (339.1 MiB). Windows 10/11, 64-bit. The model (2.5 GB, or the 1 GB "lite" tier) is downloaded on first run into `%USERPROFILE%\.promptfixer\models`.

**Upgrading from 0.3.0:** run the new installer over the old one. Your library (`%APPDATA%\PromptFixer\data\library.json`) and the downloaded model are outside the install folder and stay as they are.

**Verify:** installer SHA-256 `a8748c36186d3b4ff0d16e81ab7e4044ab481caab1ada5ff547685893b1ff566` (`SHA256SUMS.txt` is attached). PowerShell: `(Get-FileHash .\PromptFixer-0.4.0-win-x64.exe).Hash.ToLower()` must equal it.

**Not code-signed yet:** Windows shows "Windows protected your PC" → *More info* → *Run anyway*. Compare the hash first if in doubt. Full guide: `docs/INSTALL.md`.

**macOS (added 16 Oct 2026):** `PromptFixer-0.4.0-mac-arm64.dmg` (138.9 MiB, Apple Silicon) and `PromptFixer-0.4.0-mac-x64.dmg` (144.1 MiB, Intel), macOS 13 or later, built by hand with `npm run dist:mac` from the 0.4.0 sources and attached to the same release; `SHA256SUMS.txt` on the release lists them next to the installer. SHA-256 `5950705c72d5e19e6b2abd7d8d334db50dabcee3c595b3248488303c814c17fa` (Apple Silicon) and `6a5d3963ee807391be127626bee786bddf24a403a65de8546bf4feb4e7ea4b0c` (Intel); Terminal: `shasum -a 256 ~/Downloads/PromptFixer-0.4.0-mac-arm64.dmg`. The app is ad-hoc signed and not notarized, so the first launch is refused: *Done*, then **System Settings → Privacy & Security → Open Anyway**, once. On Apple Silicon the model runs on the GPU through Metal; on an Intel Mac, on the CPU.

Why the installer is this large: it ships prebuilt CPU, Vulkan and CUDA llama.cpp backends so the right one is picked at runtime. The `.blockmap` is only for future differential updates.
