## Whetprompt 0.7.0 — API keys in Settings

Whetprompt lints, scores and rewrites LLM prompts with a built-in local model (Qwen3 4B), and nothing you type leaves your machine. Cloud providers (Anthropic, OpenAI, Gemini, OpenRouter, Ollama) are optional.

**New in 0.7.0: Settings, where a cloud provider's API key goes.** Press **Settings** in the top bar, paste your key next to Anthropic, OpenAI, OpenRouter or Google Gemini and press **Save key**: the provider works at once, with no file to edit and no restart. **Test** asks the provider whether it accepts the key, and a saved key is never shown again. Pick a provider that has no key and the results pane says so, with **Add key**. Keys are saved on this computer, in the `.env` file the app already read, so a key put there by hand shows as saved; [docs/PRIVACY.md](../PRIVACY.md) says where it is kept and what **Test** sends.

Also fixed: fixing a prompt with the current Claude models, Claude Opus 5.5 among them, which refuse the `temperature` setting every request used to carry; and the top bar, which ran off the side of a window between 900 and 1023 pixels wide. Everything else is in [CHANGELOG.md](../../CHANGELOG.md#070---2026-10-28).

**Download:** `Whetprompt-0.7.0-win-x64.exe` (339.2 MiB). Windows 10/11, 64-bit. The model (2.5 GB, or the 1 GB "lite" tier) is downloaded on first run into `%USERPROFILE%\.whetprompt\models`, unless PromptFixer already downloaded it into `%USERPROFILE%\.promptfixer\models`, which Whetprompt then uses. Installing over 0.6.0 keeps your library, your keys and the model.

**Verify:** installer SHA-256 `c11bff46a8298a16cb26ea1b9c307e0327e3be82f1fe2994b137575bf8319e41` (`SHA256SUMS.txt` is attached). PowerShell: `(Get-FileHash .\Whetprompt-0.7.0-win-x64.exe).Hash.ToLower()` must equal it.

**Not code-signed yet:** Windows shows "Windows protected your PC" → *More info* → *Run anyway*. Compare the hash first if in doubt. Full guide: `docs/INSTALL.md`. The [Microsoft Store](https://apps.microsoft.com/detail/9P750H35HR59) version is signed by the Store, and moves to 0.7.0 once Microsoft has certified it.

**macOS:** no disk images for 0.7.0 yet. The macOS download is still 0.4.0, from before the rename, so the app it installs is called PromptFixer; its images and their hashes are on the [v0.4.0 release](https://github.com/Osman19702/Whetprompt/releases/tag/v0.4.0).

Why the installer is this large: it ships prebuilt CPU, Vulkan and CUDA llama.cpp backends so the right one is picked at runtime, and the Visual C++ runtime next to them. The `.blockmap` is only for future differential updates.
